# Privacy Policy

Effective date: August 24, 2026

Pytest Blackbox is a skills-only plugin for Codex and Claude Code. It does not
operate a hosted service, require an account, or include analytics, telemetry,
advertising, or tracking.

## Project data

When a user invokes the plugin, the host application may allow the model to
inspect and modify files or run commands according to the user's request and
the host's permission controls. The bundled discovery and audit scripts read
local project files to produce local reports. They do not transmit project
content to the plugin publisher.

The plugin publisher does not receive, collect, store, or sell source code,
test data, prompts, command output, credentials, or other project information
through this plugin.

## Third-party services

Codex, Claude Code, GitHub, package registries, and any infrastructure or tools
used by the user's project are third-party services with their own terms and
privacy practices. This policy does not govern data processed independently by
those services.

## Data retention

Because the plugin has no backend and the publisher does not receive plugin
usage data, the publisher retains no user or project data through the plugin.
Local files and host-side activity remain subject to the user's environment and
the host application's controls.

## Security and support

Do not include secrets, credentials, private source code, or personal data in a
public support request. Report non-sensitive issues through the
[GitHub issue tracker](https://github.com/ave-satan/pytest-blackbox-skill/issues).

## Changes

Material changes to this policy will be published in this repository with an
updated effective date.
